SHIP AI is an agentic software development platform that automates issue handling, code generation, review, and testing using AI agents. It integrates with tools like GitHub, Linear, and Jira, offering a low‑cost, high‑quality solution for engineers, solo founders, and teams to accelerate reliable software delivery while maintaining control and security.

**Areas:** AI coding agents · autonomous software delivery · agentic SDLC · software development · code review · cost optimization

## How this profile is made

API Evangelist profiles a company's public API surface the way a developer would find it: the website, developer portal and documentation, the specifications it publishes, its public repositories, and its pricing, status and changelog pages. From that it derives the properties above — contracts split per API, workflows, schemas, collections, governance rules, plans and rate limits — and scores them against the published [Kin Score rubric](https://github.com/api-evangelist/kin-score).

The artifacts are published on [APIs.io](https://apis.io), not in this repository. This repository is the public record for SHIP AI: the place to say something is wrong, missing or out of date, and to ask for a re-score or a removal.
